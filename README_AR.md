# EXCEL INTELLIGENCE PRO — دليل التشغيل والنشر

## ما الذي تتضمنه النسخة؟
- واجهة عربية/إنجليزية مع تبديل اللغة.
- رفع ملفات XLSX وXLS وXLSM وCSV.
- قراءة جميع الشيتات داخل ملف Excel.
- مؤشرات: عدد السجلات، الأعمدة، الخلايا الفارغة، الصفوف المكررة.
- تحليل أنواع الأعمدة والملخصات الرقمية.
- استكشاف البيانات.
- تحليل مخصص برسوم Bar / Pie / Line / Histogram.
- تسجيل دخول وحفظ سحابي عند ربط Supabase.

## مهم قبل الاستخدام
هذه نسخة MVP أولية. لا ترفع مستندات عمل سرية قبل إعداد Supabase والتأكد من سياسات الخصوصية والصلاحيات. في وضع المعاينة بدون Supabase، البيانات تبقى داخل جلسة التطبيق المؤقتة ولا يوجد حفظ دائم.

## النشر المجاني المقترح
1. أنشئ حساباً في GitHub.
2. أنشئ حساباً في Streamlit Community Cloud.
3. أنشئ مشروعاً مجانياً في Supabase.
4. في Supabase افتح SQL Editor وشغّل محتوى `supabase_setup.sql`.
5. أنشئ مستودع GitHub وارفع ملفات هذا المشروع إليه.
6. في Streamlit Community Cloud اختر New app وحدد المستودع وملف `app.py`.
7. من إعدادات التطبيق افتح Secrets وأضف:

```toml
SUPABASE_URL = "رابط مشروع Supabase"
SUPABASE_ANON_KEY = "مفتاح anon/public الخاص بالمشروع"
```

8. أعد تشغيل التطبيق. سيظهر تسجيل الدخول وإنشاء الحساب، وسيتم رفع الملفات إلى Bucket خاص بالمستخدم.

## حدود الخطة المجانية
- Streamlit Community Cloud مجاني، لكنه يفرض حدوداً على موارد التشغيل وقد يتوقف التطبيق أو يبطؤ عند تجاوزها.
- Supabase Free يتضمن حالياً 1GB تخزين ملفات، وحداً أقصى 50MB للملف، وقاعدة بيانات 500MB، وقد يتم إيقاف المشروع بعد أسبوع من عدم النشاط.
- الخطة المجانية مناسبة للتجربة والاستخدام الشخصي الخفيف وليست ضماناً لخدمة إنتاجية حرجة أو أرشيف مستندات طويل الأجل.

## ملاحظات تطوير
النسخة الحالية تحلل البيانات رقمياً وتتيح إنشاء الرسوم حسب الأعمدة. المرحلة التالية المقترحة:
- استرجاع الملفات السابقة من التخزين السحابي داخل التطبيق.
- تحليل العلاقات بين الشيتات.
- تقارير PDF عربية/إنجليزية.
- تعريف دلالات أعمدة المقاولات مثل IR/RFI/MIR وOPEN/CLOSE.
- مساعد أسئلة وأجوبة على البيانات مع توضيح مصدر كل إجابة.
